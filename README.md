## cinematch-website
CineMatch is a simple website that makes it easy to keep track of movies by marking them as watchlist or watched. It allows users to organize their movie collection, keep track of what they have watched, and manage movies they want to watch in the future.

## Dataset
The movie dataset used in this project was obtained from the [TMDB Movies Dataset 2020](https://www.kaggle.com/datasets/radioactive11/tmdb-movies-dataset-2020) available on Kaggle. The dataset contains various movie-related information, including movie titles, genres, release dates, ratings, popularity, and other details. It is used as the main source of movie data in CineMatch, allowing users to browse movies and manage their watchlist and watched movies.

## Purpose
This project was created as a personal learning project to improve my skills and gain hands-on experience in website development. Through CineMatch, I explored the process of building a web application, working with databases, and implementing features for managing movie data.
